Instrument

A benchmark tells you which model scored better.
Aionoscope shows you what it learned.

Aionoscope runs frozen-feature offline probes on the balanced Aiono basic-components generator against foundational time-series models, and writes one JSON result per run. Two surfaces read those artifacts: the dashboard for the numbers, the viewer for the representation geometry they came from.

  • Probes Aionoscope Linear Probe Dashboard Per-model probe metrics across the balanced basic-components generator: best-layer selection, encoder runtime, and through-layer parameter counts, aggregated in the browser from the generated JSON results. Open →
  • Geometry Aionoscope Manifold Viewer Static reader for controlled manifold-slice artifacts. Metrics are computed in Python over all stored grid points; the browser only renders the selected record. Open →
